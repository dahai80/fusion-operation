## 二、核心问题诊断

四个根因，全部有真实数据支撑，非猜测：

### 根因 1：选题撞车（0 播放主因）

- 现象：周片 14/26 = 0 播放（54%）。撞车主题：太阳压缩×6、时间倒流×3、地球磁场×3、黑洞×3。
- 代码根因：`topic_gen.py:58-67` 排除只到**标题级**（`pub_titles`/`pend_titles`/`blacklist` 全是完整标题），把前 30 条标题塞给模型让它「自律不重复」。同主题换标题（太阳压缩成芝麻/豌豆/硬币/1米/口袋）绕过标题去重。**无代码级硬去重**。
- 证据：`_load_published_titles` 取 `item.get("topic")`，6 个太阳压缩片 topic 全不同字串 → 全部不在排除集 → 全部重新生成。

### 根因 2：钩子泛、无完播/分享驱动（max 未破千主因）

- 现象：max 503，全库仅 1 个破 500。破千公式已验证有效（极端数字+反常识），但未爆。
- 代码根因：`mlx_script.py` SYSTEM_PROMPT 只说「首句 3 秒强钩子」无**强度标准**；ending_hook 有选择题+关注引导，**无分享/完播驱动**（完播率是抖音推荐核心权重，分享是破圈杠杆）。
- 数据：TOP3 都是极端数字开头（1米太阳=503/地球磁场=382/时间倒流=350），证明钩子方向对但力度不够。

### 根因 3：模板词污染（劣片共性未在代码层拦截）

- 现象：模板词「用AI把知识画出来，一眼就记住」出现在多个 0 播放视频。
- 代码根因：`winning_patterns.json` 已把该词列入 `losing_patterns`，但 `topic_gen._load_pattern_hint` 只把 losing_patterns 前 4 条作为**软提示**塞进 user_msg（靠模型自觉），SYSTEM_PROMPT **无硬禁词**。模型仍生成含模板词的选题。
- 证据：losing_patterns 列了「通用模板词」，但 stats_history 里 0 播放片仍带该词 → 软提示失效。

### 根因 4：选题自残（同实体反复消耗）

- 现象：太阳压缩系列×6，把一个有效钩子模板用烂。前 1-2 个有效，3-6 个平台判定重复降权 → 全 0。
- 代码根因：同根因 1，标题级去重无法识别「太阳」「压缩」「坍缩」是同一实体。`topic_gen` 无实体级频次上限。
